# Sales & Profit Dashboard (Excel)

## Project Overview
This project is an interactive Sales & Profit Dashboard created in Microsoft Excel to analyze business performance across categories, states, and time periods.
-----------------------------------------------------------------------------------------------------------------------------------------------
## Tools Used
* Microsoft Excel
* Pivot Tables
* Pivot Charts
* Slicers
* Data Visualization
-----------------------------------------------------------------------------------------------------------------------------------------------
## Key Insights
* Track total sales and total profit
* Analyze yearly profit trends
* Identify top 5 profitable customers
* Monitor monthly sales performance
* Category-wise and state-wise sales distribution
